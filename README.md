# yii2-apexchart-asset

yii2-apexchart-asset is a Yii2 asset bundle for integrating ApexCharts into your Yii2 applications. This asset bundle simplifies the process of including ApexCharts in your web applications, making it easier to create interactive and visually appealing charts.

## Features

- Easy integration of ApexCharts with Yii2 applications.
- Supports multiple chart types (line, bar, pie, etc.).
- Lightweight and easy to use.

## Installation

You can install this package via Composer. Run the following command in your terminal:

```bash
composer require strtob/yii2-apexchart-asset
